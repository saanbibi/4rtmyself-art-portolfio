# PNG Files

This folder contains the exported PNG versions of the finished Chibi Pixel Art artworks.

These files are provided for easy viewing and sharing without requiring Aseprite.

## File Format

- `.png` — Exported artwork previews

## Contents

Each PNG file corresponds to a finished chibi pixel-art portrait from the project.

## Software

Artwork created using [Aseprite](https://www.aseprite.org/).

> **Note:** These artworks are part of my personal art portfolio. Please do not redistribute, modify, or use the artwork without permission.
