# Aseprite Files

This folder contains the original editable Aseprite source files for the Chibi Pixel Art project.

## Contents

The files in this folder contain the original artwork layers and editable elements used to create each chibi pixel-art portrait.

### File Format

- `.aseprite` — Aseprite project files

## Software

These files were created and edited using [Aseprite](https://www.aseprite.org/).
