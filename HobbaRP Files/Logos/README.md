# HobbaRP Logos

A collection of logos and branding assets created for the HobbaRP project.

These assets are used to represent the HobbaRP brand across the game, interfaces, and other project-related materials.

## Asset Categories

- Main Logos
- Alternative Logos
- Logo Variations
- Branding Elements

## File Formats

- `.png` — Exported raster images
- `.svg` — Scalable vector graphics
- `.aseprite` — Editable Aseprite source files, when applicable

## Source Files

Editable source files are organized in the corresponding source file folders when available.

Some logos may have been created or edited using Figma.

## Tools

- Aseprite
- Figma

## Usage

These assets are created for the HobbaRP project and should not be redistributed, modified, or used outside of the project without permission from the respective creators.
