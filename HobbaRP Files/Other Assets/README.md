# HobbaRP Other Assets

A collection of additional visual assets created for the HobbaRP project that do not fall under the Logos, Icons, or UI Assets categories.

This folder serves as an archive for miscellaneous graphics and other project-related visual resources.

## Asset Categories

- Illustrations
- Pixel Art
- Decorations
- Backgrounds
- Promotional Graphics
- Miscellaneous Assets

## File Formats

- `.png` — Exported images and graphics
- `.svg` — Scalable vector graphics, when applicable
- `.aseprite` — Editable pixel-art source files, when applicable

## Source Files

Editable source files are stored in their corresponding source file folders when available.

Assets created using Figma may be provided as `.png` or `.svg` exports, while the editable source is maintained in Figma.

## Tools

- Aseprite
- Figma

## Usage

These assets are created for the HobbaRP project and should not be redistributed, modified, or used outside of the project without permission from the respective creators.
