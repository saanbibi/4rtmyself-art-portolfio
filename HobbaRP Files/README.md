# HobbaRP Files

A collection of visual assets and design resources created for the HobbaRP project.

This folder serves as an organized archive for the project's logos, icons, UI elements, and other graphical assets used throughout the game and its related interfaces.

## Project

**HobbaRP** is a Habbo-inspired retro roleplay project featuring custom visual assets and interfaces designed for the game's community and experience.

## Asset Categories

### Logos
Contains official and alternative logos created for HobbaRP.

### Icons
Contains custom icons used for navigation, features, menus, and other in-game interfaces.

### UI Assets
Contains graphical elements used for the game's user interface and other interactive components.

### Other Assets
Contains additional visual resources and graphics that do not fall into the categories above.

## Purpose

This repository is used to organize and archive the visual assets created for HobbaRP, making it easier to manage, update, and reference project files throughout development.

## Tools

Assets may be created or edited using various design and pixel-art tools, including:

- Figma
