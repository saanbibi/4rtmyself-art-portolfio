# HobbaRP Files

A collection of visual assets and design resources created for the **HobbaRP** project.

This folder serves as an organized archive of the project's logos, icons, UI elements, and other graphical assets used throughout the game and its related interfaces.

## Project

**HobbaRP** is a Habbo-inspired retro roleplay project featuring custom visual assets, interfaces, and design elements created for its community and gameplay experience.

## Asset Categories

### Logos

Contains official and alternative logos, branding elements, and logo variations created for HobbaRP.

### Icons

Contains custom icons used for navigation, features, menus, and other in-game interfaces.

### UI Assets

Contains graphical elements and visual resources used throughout the game's user interface and interactive components.

### Other Assets

Contains additional visual resources and graphics that do not fall under the Logos, Icons, or UI Assets categories.

## File Formats

- `.png` — Exported images and graphical assets
- `.svg` — Scalable vector graphics, when applicable
- `.aseprite` — Editable Aseprite source files, when applicable

## Tools

Assets may be created or edited using various design and pixel-art tools, including:

- Aseprite
- Figma

## Source Files

Editable source files are organized separately from exported assets whenever applicable.

Some designs may be created using Figma. In these cases, the editable source is maintained in the respective Figma project, while exported assets are archived here as `.png` or `.svg` files.
