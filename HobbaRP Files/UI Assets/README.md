# HobbaRP UI Assets

A collection of user interface assets and visual elements created for the HobbaRP project.

These assets are used to build and support the game's user interface and overall visual experience.

## Asset Categories

- UI Elements
- Buttons
- Panels
- Headers
- Navigation Elements
- Interface Decorations
- Other UI Graphics

## File Formats

- `.png` — Exported UI graphics and images
- `.svg` — Scalable vector graphics, when applicable
- `.aseprite` — Editable pixel-art source files, when applicable

## Source Files

Editable Aseprite files are stored in the `Aseprite Files` folder.

UI designs and interfaces created in Figma are maintained in their respective Figma projects. Exported assets are provided as `.png` or `.svg` files when applicable.

## Tools

- Figma
- Aseprite

## Usage

These UI assets are created for the HobbaRP project and should not be redistributed, modified, or used outside of the project without permission from the respective creators.
