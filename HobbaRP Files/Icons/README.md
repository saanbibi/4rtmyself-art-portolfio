# HobbaRP Icons

A collection of custom icons created for the HobbaRP project.

These icons are designed for use across the game's interface, navigation, features, menus, and other interactive elements.

## Asset Categories

- Navigation Icons
- Feature Icons
- Interface Icons
- Game Icons
- Miscellaneous Icons

## File Formats

- `.png` — Exported icon images
- `.svg` — Scalable vector icons
- `.aseprite` — Editable pixel-art source files, when applicable

## Source Files

Editable Aseprite files are stored in the `Aseprite Files` folder.

Vector-based icons and designs created in Figma may be provided as `.svg` or `.png` exports, with the editable source maintained in Figma.

## Tools

- Aseprite
- Figma

## Usage

These icons are created for the HobbaRP project and should not be redistributed, modified, or used outside of the project without permission from the respective creators.
